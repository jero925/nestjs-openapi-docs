# Changelog

All notable changes to this skill project will be documented in this file.

The format is based on Keep a Changelog and this project follows a simple date/version history.

## [1.1.0] - 2026-05-10

### Added

- `npx` installer support through `package.json` and `bin/install.js`.
- Command-line installation modes for current project, specific project, and current user.
- README guidance for `npx`-based installation and usage.

### Changed

- Switched the recommended installation flow from manual copying to `npx nestjs-openapi-docs`.
- Removed machine-specific paths and personal metadata from project documentation.

## [1.0.0] - 2026-05-10

### Added

- Initial `nestjs-openapi-docs` skill definition.
- Live-source guidance for consulting official NestJS OpenAPI documentation.
- Cross-checking rules for the official `sample/11-swagger` example.
- English README with installation, usage, sharing, and maintenance instructions.
- MIT `LICENSE` file.

### Changed

- Translated all skill-project documentation to English.
